## 图片质量和核对

- 使用原始 PNG 截图，建议有效内容宽度约 1200～1800 像素；以文字清晰为准，避免把小图强行放大。
- 裁去任务栏、桌面和大块无关空白；可以保留必要窗口边缘，帮助第一次使用 Unity 的读者辨认位置。
- 私人用户名、绝对磁盘路径和无关项目名称可以遮挡；不要遮住文件名、按钮、表名、坐标或结果摘要。
- 截图中的按钮名称应与工具一致。成功与失败图片使用真实状态，不通过图片编辑修改状态、错误原因或统计数字。
- 补图后在 GitHub 预览 README：五张图能打开，说明文字完整，没有残留的无效图片地址；没有提供的图继续保留隐藏占位即可。
